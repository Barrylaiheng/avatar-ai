# 洪拳详解（工字伏虎拳 · 铁线拳）

> 文档定位：《武学知识体系实战应用 SOP》在"对方力量压迫 / 下潜抱摔 / 三段轮转 Round 2 压制段 / 体力下降回太极休息之前"四类场景直接引用本文的 工字伏虎、铁线拳、沉桥挑桥、防摔组合。图谱构建时请将本章所有关键词，与 SOP §2.3 / §3 表 第三四行 / §4 Round 2 / §5 强化建议 扎马 等节点连边。

---

## 0. 核心理念

**洪拳 = 硬桥硬马 + 发声催力 + 功力训练**。
- **硬桥**：前臂（桥手）像木棍一样硬，对方打过来，我不是"化"而是"硬接/硬截"；
- **硬马**：马步扎实（四平马、弓字马），脚下生根，重心极低防摔倒；
- **发声催力**：出击时呼"嚯""嘀""威"等短音，把丹田力送到拳面；
- **功力优先**：先练 铁线拳 / 伏虎拳 单式，单式够硬再练组合。

关键词：**硬桥硬马、四平马、弓字马、工字伏虎、铁线拳、沉桥、挑桥、截桥、撞拳、发声催力、扎马**

SOP 交叉引用关系：
- SOP §2.3 场景 C（对方身板厚实 / 力量型压迫 / 下潜抱摔）→ 引用本文 §2.1 扎马 / §3.2 沉桥挑桥 / §4.3 防摔组合
- SOP §3 切换条件表「连续被下潜 2 次 / 险些摔倒」→ 咏春或太极切到洪拳
- SOP §3 切换条件表「体力 < 30%」→ 由洪拳切回太极恢复呼吸
- SOP §4 Round 2 · 压制段 → 完整走本文 §4.2「扎马→沉桥→工字→撞拳→挑桥」
- SOP §5 强化建议「重心不稳」→ 本文 §2.1 扎马，弓字步 10 组 × 每腿 30 秒

## 1. 基本功要求

### 1.1 四平马（洪拳入门之根）
- 双脚尖向前开 2.5 个肩宽；
- 双膝下蹲，使大腿与地面平行（"平"= 大腿平）；
- 脚尖、膝、胯、肩四点要四平；
- 标准：**提高班 ≥ 5 分钟 / 组，每日 3 组**；少年班从 1 分钟起。

### 1.2 弓字马（实战移动中的基础马步）
- 一脚前弓（前膝垂线不超脚尖），一脚后蹬（后膝伸直不锁死）；
- 重心 70% 在前腿、30% 在后腿；
- SOP §5 强化建议"重心不稳"的处方 = 弓字步 10 组 × 每条腿 30 秒。

### 1.3 桥手硬度（功力训练）
- 器材：木人桩 或 两人互碰桥（前臂内侧互撞）；
- 每日 5 分钟，配合发声"嚯"催力；
- 禁忌：练完立刻揉前臂、立刻洗冷水。

## 2. 工字伏虎拳（洪拳入门第一套）— SOP §2.3 直接引用

> 对应 SOP §2.3 场景 C：对方力大压迫、重心低、下潜近身，我用"工字"框架硬接，"伏虎"姿势防抱摔。

### 2.1 前三路：扎马 + 单弓字 + 双弓字（SOP Round2 开头三件套）
1. **扎马（四平马）**：直接从 §1.1 起势 —— 只要对方扑过来抱我双腿，我一扎马他就抱不动。（SOP §2.3 防摔第一步）
2. **单弓字**：左脚向前开成左弓字马，右拳从腰间向前打出（中拳），左掌护胸；
   - 要点：打出的拳要成"工"字：肩→肘→拳三折，像个横的"工"；
3. **双弓字**：左右弓字交替，中拳 × 2，配合"嚯、嚯"两声。

关键词共现：**扎马、四平马、弓字马、工字伏虎、单弓字、双弓字、中拳、嚯、防摔、抱腿、下潜近身**

### 2.2 中路伏虎式（Round2 中段，SOP §4 Round2 主体）
- 姿势：四平马下蹲，双拳在胸前交叉下压，像"按住一只虎"；
- 对方**下潜抱腰**时，我就变伏虎式：双拳向下压对方后颈 / 背 + 马步下沉 → 对方被压得钻不进来。
- SOP 对应：§2.3 场景 C 的防下潜第二步。

## 3. 铁线拳（洪拳功力深化）

> 铁线拳 = "每条桥手都像一根铁线一样，刚中带柔"。实战不是用套路打，而是抽出单个式子插在 Round 2 的对打节奏里。

### 3.1 十二桥手总览
- 定、软硬、逼、直、分、寸、提、留、运、制、订、穿；
- 进入 SOP 轮转前只要掌握 2 条最常用：**沉桥、挑桥**。

### 3.2 沉桥 + 挑桥（SOP §2.3 + §4 Round 2 + §3 咏春→洪 / 太极→洪 切换衔接）
> **本文核心章节。SOP Round 2 的主骨架就是「沉桥接 → 工字 → 撞拳 → 挑桥反击」。**
> 关键词：**沉桥、挑桥、铁线拳、硬桥、十二桥手**

1. **沉桥（Tsun Kiu，向下沉）**：
   - 前臂平行地面，自上往下沉压；
   - 用途 1：对方**下潜用肩膀撞我丹田**（SOP §2.3 场景 C），我沉桥压对方后肩；
   - 用途 2：咏春拳做完 伏手 之后立刻切洪拳 —— **伏手压一下 → 沉桥再接一下**，两步都压，对方下潜的那个"钻"就直接被掐死。
2. **挑桥（Tiu Kiu，向上挑）**：
   - 前臂从下方向上向外弧线挑起；
   - 用途 1：对方直拳打我上盘，我沉桥接完 → 立刻挑桥把对方整条臂**掀起来** → 对方肋骨空了 → 我撞拳补刀；
   - 用途 2：太极 Round1 结束后 → 懒扎衣掤完 → 挑桥接对方第二拳，进入 Round2 洪拳压制；
   - 用途 3：《洪拳详解》§4.3 防摔组合的第二步。

### 3.3 发声催力（配合沉 / 挑 / 撞）
- 沉桥 → "嘀"（短促丹田音）；
- 挑桥 → "嚯"（稍长）；
- 撞拳 → "威"（最长，音从丹田升到头顶）。

## 4. 实战组合（SOP §2.3 / §4 Round 2 直接走）

### 4.1 入门级 4 连（新学员场景 C 应急）
```
扎马（防抱摔第一步） → 沉桥（压对方下潜肩） → 中拳（打心口） → 挑桥（掀对方手）
```
- 时间 ≤ 0.9 秒；
- SOP §2.3 场景 C 的新手推荐。

### 4.2 提高班 5 连（SOP §4 Round 2 · 压制段 · 必走完整）
```
① 扎马（四平马，一蹲到底，防抱腿）
  ↓ 对方打直拳或摆拳
② 沉桥（硬接对方一拳，"嘀"）
  ↓ 接完后立刻换形
③ 工字（弓字马 + 中拳，打对方心口，"嚯"）
  ↓ 对方退半步想缓
④ 撞拳（进步贴身，右拳横撞对方丹田 / 肋下，"威"）
  ↓ 对方想伸手拦
⑤ 挑桥（掀对方拦的那条臂，留出上盘空间给 Round3 咏春接）
```
共 5 个动作，总时长 ≤ 1.0 秒。第 ⑤ 挑桥的"留空上盘"作用 = 与 SOP Round 3 咏春日字冲拳无缝衔接。

### 4.3 防摔三连（SOP §3「连续被下潜 2 次 / 险些摔倒」时触发）
```
截桥（对方手刚碰到我腰时，我横着一拦） → 挑桥（把对方手向上掀起来） → 撞拳（打对方肋骨，把他压退回去）
```
- 对应 SOP §2.3 具体调用章节列表的第 3 条：《洪拳详解》§4.3；
- 图谱关系：SOP 场景 C、切换条件表第三行、Round 2 压制段、防摔建议 → 四个节点都要能 1 跳或 2 跳到达这一式三连。

## 5. 常见错误与修正

| 错误现象 | 根源 | 修正方法 |
|---|---|---|
| 对方抱我双腿立刻被抱起来 | 四平马没扎到底 | 回到 §1.1 四平马 5 分钟 × 3 组，直到教练推不动 |
| 沉桥接拳后自己退了一步 | 桥手硬功不够，马步没合 | 互碰桥手 + §4.1 入门四连每天 100 组 |
| 工字打出去上半身前倾过头 | 没有"弓字"前弓后蹬的分配 | §1.2 弓字马定桩，每条腿保持 30s 不晃 |
| 挑桥只动手不动腰 | 挑桥用的是腰力，不是臂力 | 扎马 + 单练挑桥：腰先转 20°，桥手再跟着挑 |
| 撞拳撞空对方躲开 | 撞拳之前必须先沉桥压住对方一手 | 按 §4.2 顺序，不允许跳步直接撞 |

## 6. 与其他拳法的关系图谱（显式跨文档边源）

- **对 太极拳 的关系**：
  - 太极 = 接（化），洪拳 = 顶（硬接硬撞）；
  - SOP §3 切换条件：体力 < 30% → 洪拳切回太极（本文 §6 → 太极 §4 松沉心法恢复呼吸）；
  - 衔接招式：洪拳 **沉桥** 卸力后 → 太极 **起势抱球**（太极 §2.1 第 1 式）+ 无极桩呼吸。

- **对 咏春拳 的关系**：
  - 咏春 = 对方顶完后我钻进去（近身短打）；
  - 洪拳 = 对方钻进来时我顶住（防摔 + 压制）；
  - SOP §3 切换条件：险些摔倒 / 下潜 2 次 → 咏春切洪拳；
  - 衔接招式：咏春 **伏手** 压完 → 洪拳 **沉桥** 接对方下潜（本文 §3.2）→ §4.3 防摔三连。

- **对 SOP 总表的关系**：
  - 本文 §2.1 工字伏虎 / §3.2 沉桥挑桥 / §4.3 防摔组合 都在 SOP 里有显式引用链接；
  - 图谱要求：SOP「场景 C / Round 2 压制 / 防摔切换 / 重心不稳的扎马强化」四个节点 → 本文对应章节，1~2 跳可达。
