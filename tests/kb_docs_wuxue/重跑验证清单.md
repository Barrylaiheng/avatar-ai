## 1. 第一步 · 清空现有知识库（你说的"全删掉，重新跑"）

1. 打开 MVP → 左侧导航「知识库」；
2. 对每一张存在的知识库卡片：
   - 点右下角 🗑「删除」按钮；
   - 弹出删除确认对话框 → **确认**；
   - 连续点，直到列表页一张卡片都不剩（显示"还没有任何知识库 · 新建一个"空态）；
3. **可选兜底（如果你想从数据库层面保证干净）**：
   ```
   关闭 MVP → 删掉  data/mvp.db  → 重开 MVP
   ```
   这样会把所有智能体、配置、知识库全部重置。**注意：如果想只清知识库、保留智能体，只走 UI 卡片删除即可，不要直接删 db 文件。**
4. 验证结果：
   - ✅ 知识库列表 = 空态卡片 1 张；
   - ✅ 智能体列表（如果选择只清 KB 而保留智能体）= 仍然都在，但每个智能体的「绑定知识库」下拉都显示为"不绑定"。

## 7. 失败回退 / 常见坑（如果某一步没过按这里查）

| 现象 | 大概率原因 | 回退操作 |
|---|---|---|
| AI 构建图谱时仍弹"无法识别是哪个知识库"的深色 modal | 虽然做了 fallback，但 _kbCache 此时还是空的（例如：直接从空态 KB 页进入管理弹窗，文档还没被 Bridge 拉回来过） | 先切「切片库」Tab 等 2 秒（文档列表一刷出来 _kbCache 就有了）→ 再切图谱 Tab 点构建 |
| 图谱 nodes ≥ 27 但 SOP 节点跟太极/咏春/洪拳节点之间没边 | 说明 chunk 抽取时关键词没被并成同一个实体（大小写 / 同义不同写法） | 检查对应拳法第 6 节"与其他拳法的关系图谱"有没有缺关键词，直接在文档里补上同一关键词后重新上传 + 重新切片 + 重新构建 |
| 图谱有边但端到端问答没引用拳法分文，只引用了 SOP | RAG 检索的 top_k 不够 / SOP 太长被 chunk 占满了 top_k | 把 RAG 的 top_k 从默认值（例如 6）提到 12；或在拳法分文的 §1.2、§3.2 等关键位置，多重复两次"拳法名 + 场景名 + 具体招式名"三个词共现 |
| 编辑智能体保存后，绑定变成"不绑定" | `openAgentModal` 的回填 / `kb_ids` 字段有脏数据（例如存成了字符串 "1" 而不是数组 `["1"]`） | 去 data/mvp.db 查 agent 表的 kb_ids 列，确认是 JSON 数组格式；回到管理页重新绑定一次，再保存再打开验证 |
