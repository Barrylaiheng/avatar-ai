# 武学知识体系实战应用 SOP

> 文档定位：本 SOP 是**「武学知识体系」知识库的总索引 / 总入口**，为实战教学场景规定"什么时候用哪门拳法、按什么顺序出招、出现什么特征切换思路"。本 SOP 的**每一条判断分支**都会引用《太极拳详解》《咏春拳详解》《洪拳详解》三篇分文档中的具体招式与心法章节，目的是让知识图谱能把"SOP 决策节点"与"三拳法内部的招式/关键词"连成一个多文档合一的知识体系。

---

## 0. 适用范围与对象

本 SOP 面向三类学员：
- **少年班（8–14 岁）**：基础打稳，优先学习 洪拳 的桥马硬功；
- **成年入门班（18–35 岁）**：身体条件一般，优先学习 太极拳 的听劲与松沉，再过渡到 咏春拳 的短桥快打；
- **教练提高班**：三门拳法皆需掌握，能够在对练中按本 SOP 自由切换使用。

核心关键词：**太极拳、咏春拳、洪拳、听劲、沉桥、扎马、小念头、老架一路、工字伏虎**

## 1. 实战决策总流程图（文本版）

```
[对练开局]
   │
   ├─ 对方身高 > 180cm / 臂展长 / 直拳开路 ──► 采用「太极拳」粘化打法（见 3.1）
   │
   ├─ 对方身高 ≤ 170cm / 步子密 / 近身推搡  ──► 采用「咏春拳」日字冲拳（见 3.2）
   │
   └─ 对方身板厚实 / 力量型压迫 / 低架稳    ──► 采用「洪拳」桥手硬接（见 3.3）

[第 1 回合 30 秒内未得分]
   │
   ├─ 我方重心稳定、呼吸顺 ──► 保持当前拳法，强化 招式组合（三拳法 §2 组合连击）
   │
   └─ 我方被击中 ≥ 2 次 ──► 强制切换：太极拳 → 洪拳 → 咏春拳 的「松-硬-快」三段轮转（见 §4）
```

## 2. 场景决策分支（直接引用三拳法章节）

### 2.1 场景 A：对方使用长拳、直拳、摆拳开路
**推荐拳法：太极拳**
- **决策依据**：太极拳 以柔克刚 的核心理念，配合「掤捋挤按」四正手，最适合消解长线力道。
- **具体调用章节**：
  - 《太极拳详解》§2.1 老架一路 · 起势与懒扎衣（第 1–3 式）
  - 《太极拳详解》§3.2 听劲 · 粘化四法（掤、捋、挤、按）
  - 《太极拳详解》§4 松沉心法 · 气沉丹田（第 2 段「命门后撑」细节）
- **关键词锚定**：松沉、听劲、粘化、掤捋挤按、懒扎衣、气沉丹田

### 2.2 场景 B：对方使用近身短打、贴身顶肘
**推荐拳法：咏春拳**
- **决策依据**：咏春拳 中线理论 + 短桥快打，适合近距离空间狭窄的连续出拳。
- **具体调用章节**：
  - 《咏春拳详解》§2 小念头 · 日字冲拳 与 摊膀伏 三式
  - 《咏春拳详解》§3.1 黐手 · 单黐与双黐的 触觉训练
  - 《咏春拳详解》§4.2 实战组合 · 「问手→伏手→冲拳」三连
- **关键词锚定**：中线、日字冲拳、黐手、问手、摊膀伏、短桥

### 2.3 场景 C：对方使用低扫、抱摔、下潜近身
**推荐拳法：洪拳**
- **决策依据**：洪拳 桥马扎实、铁线拳 功力深厚，适合硬桥硬马接招，稳重心防摔倒。
- **具体调用章节**：
  - 《洪拳详解》§2.1 工字伏虎拳 · 前三路 扎马与单弓字
  - 《洪拳详解》§3.2 铁线拳 · 沉桥 与 挑桥 两式
  - 《洪拳详解》§4.3 对练 · 「截桥→挑桥→撞拳」防摔组合
- **关键词锚定**：工字伏虎、铁线拳、沉桥、挑桥、扎马、硬桥硬马

## 3. 拳法切换触发条件（强约束）

> 教练/智能体 输出建议时必须**逐条核对**；三条全中则必切拳法。

| 触发条件 | 由当前 X 拳法 | 切到 | 理由（引用分文档章节） |
|---|---|---|---|
| 连续 3 次接招失败，且出现「被对方长手压着打」 | 咏春拳 | 太极拳 | 《太极拳详解》§3.2 粘化四法 可通过 掤手 抬高对方长手 |
| 连续 3 次被逼退至圈边，空间 < 1 米 | 太极拳 | 咏春拳 | 《咏春拳详解》§4.2 问手→伏手→冲拳 三连 适合窄空间爆发 |
| 连续被下潜 2 次 / 险些摔倒 | 咏春拳 / 太极拳 | 洪拳 | 《洪拳详解》§2.1 扎马 + §4.3 截桥→挑桥→撞拳 防摔组合 |
| 体力条 < 30%（喘气 / 教练叫停） | 洪拳 | 太极拳 | 《太极拳详解》§4 松沉心法 节约体力，恢复呼吸 |

## 4. 三段轮转实战模板（提高班必学）

```
Round 1（0:00–0:30）——太极拳 · 试探
   招式：起势 → 懒扎衣 → 六封四闭 → 单鞭
   目的：听劲 → 摸清对方力道曲线、出手节奏

Round 2（0:30–1:30）——洪拳 · 压制
   招式：扎马 → 沉桥 → 工字 → 撞拳 → 铁线挑桥
   目的：硬桥硬马 压重心 → 逼对方退 1 步以上

Round 3（1:30–2:00）——咏春拳 · 终结
   招式：问手 → 伏手 → 日字冲拳 ×3 → 膀手卸力 → 再冲拳 ×2
   目的：对方体能下降 → 近距离快打 终结组合
```

引用来源：
- 太极拳：老架一路（《太极拳详解》§2.1）+ 听劲（§3.2）
- 洪拳：工字伏虎（《洪拳详解》§2.1）+ 铁线沉桥挑桥（§3.2）
- 咏春拳：小念头（《咏春拳详解》§2）+ 黐手（§3.1）+ 三连冲拳（§4.2）

## 5. 结束与复盘（教学输出模板）

当一场对练结束，**智能体 / 教练 必须按下面模板**生成复盘：

```
【复盘结果】
1. 你本轮使用拳法：[太极拳/咏春拳/洪拳]（轮转次数 N）
2. 切换决策命中 / 未命中 本 SOP 第 X.X 节：命中则 ✅，未命中则引用正确分支
3. 下轮强化建议：
   - 如切换过早 → 回去练《太极拳详解》§4 松沉心法，每式站桩 3 分钟
   - 如切换过晚 → 回去练《咏春拳详解》§3.1 黐手，每日 20 分钟
   - 如重心不稳 → 回去练《洪拳详解》§2.1 扎马，每日弓字步 10 组 × 每条腿 30 秒
4. 引用章节汇总（便于点击跳转或图谱高亮）：
   - 太极拳：懒扎衣、六封四闭、单鞭、听劲、松沉
   - 咏春拳：小念头、日字冲拳、黐手、问手、伏手
   - 洪拳：工字伏虎、铁线拳、沉桥、挑桥、扎马
```
