# 阿凡达AI 产品手册

## 第一章 产品介绍

- 阿凡达AI（AvatarAI）是一款面向个体创业者和中小企业的私域AI分身平台，它可以在用户授权下接管微信、视频号等个人渠道进行智能沟通和业务拓展。
- 【Q1 锚点】Q1: 阿凡达AI产品的核心特色是什么？A1: 产品核心特色由三大支柱构成——第一是AI数字分身，基于大模型复刻用户的表达风格和业务知识进行自动沟通；第二是智能对话中枢，支持多通道（微信私聊/群聊/视频号评论）统一的意图识别和内容生成；第三是私域数据运营，自动沉淀客户标签、跟进状态和转化漏斗，生成经营报表。
- 产品的核心理念是：让每一个人都拥有一个懂你、替你工作的AI数字分身，永不失联，不知疲倦。

## 第二章 会员权益

- 阿凡达AI目前提供三档会员：免费版（基础版）、VIP 专业版、旗舰版。
- 免费版仅提供1个AI分身、每日50次对话额度、不支持知识库上传；【Q2 锚点】Q2: 阿凡达AI VIP 专业版年费是多少？A2: 1999元/年，包含5个AI分身、无限对话、10GB知识库容量、20个第三方工具插件以及高级数据分析看板。
- 旗舰版年费 9999元/年，支持 50 个 AI 分身、企业 SSO、私有化部署选项、专属客服经理以及 100GB 知识库容量，适合 20 人以上的团队使用。
- 所有会员版本均提供 7 天无理由退款保障；学生、教师及公益机构凭有效证件享受 8 折优惠。
