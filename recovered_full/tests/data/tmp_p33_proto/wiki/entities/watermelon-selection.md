# 西瓜挑选技巧

西瓜是夏季爆款，客户经常问"怎么挑才甜"。

## 五步挑瓜法

1. **看瓜脐**：瓜脐小而内凹 → 成熟度高
2. **看瓜纹**：纹路清晰、底色发黄 → 光照充足
3. **看瓜藤**：藤弯曲绿色 → 新鲜；藤直枯黄 → 存久
4. **拍瓜声**：沉闷"嘭嘭"声 → 熟；清脆"当当"声 → 生
5. **掂重量**：同样大小偏轻 → 熟（水分转化糖分）

## 客户高频问题

**Q：无籽西瓜是不是转基因？**
A：不是。无籽西瓜是通过杂交培育的，自然安全，可以放心吃。

**Q：西瓜切开能放多久？**
A：冷藏不超过 24 小时，常温不超过 4 小时。建议保鲜膜包好冷藏。
