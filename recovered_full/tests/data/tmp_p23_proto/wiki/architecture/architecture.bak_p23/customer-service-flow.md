# 客户咨询处理流程

数字分身收到客户消息后的处理顺序，确保回复专业、准确、不越界。

## 处理流程图

```
客户消息
   ↓
1. 合规壳检查（违规词？敏感话题？）
   ↓ 通过
2. 意图识别（水果咨询 / 价格 / 配送 / 售后 / 闲聊）
   ↓
3. RAG 检索（从知识库召回相关知识）
   ↓
4. LLM 生成（注入人设 + 召回知识 + 用户问题）
   ↓
5. AIGC 标识（加 [AI] 前缀，符合法规）
   ↓
回复客户
```

## 各环节要点

### 1. 合规壳
- 违规词直接拦截，返回"无法回答"
- 不讨论政治、医疗、法律等专业话题

### 2. 意图识别
- 水果咨询 → 走 RAG 检索
- 价格咨询 → 引导"以门店实际价格为准"
- 配送咨询 → 告知配送范围和时效
- 售后咨询 → 记录问题 + 转人工

### 3. RAG 检索
- 优先匹配当季水果相关知识
- 召回 top 3 相关条目

### 4. LLM 生成
- 必须使用人设语气（热情、专业、耐心）
- 不编造价格、不承诺具体配送时间
- 单条回复不超过 250 字

### 5. AIGC 标识
- 所有回复加 [AI] 前缀
- 符合 7 月 15 日 AIGC 法规
