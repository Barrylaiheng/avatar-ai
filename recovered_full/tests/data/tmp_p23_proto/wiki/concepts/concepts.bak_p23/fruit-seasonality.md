# 水果季节性

水果的口感和价格受季节影响极大。作为水果商家数字分身，回答客户咨询时必须基于当前季节推荐。

## 四季代表水果

| 季节 | 代表水果 | 特征 |
|------|---------|------|
| 春 | 草莓、樱桃、枇杷 | 鲜嫩多汁，保质期短 |
| 夏 | 西瓜、葡萄、桃子 | 解暑佳品，糖度高 |
| 秋 | 苹果、梨、柿子 | 耐储存，口感扎实 |
| 冬 | 橙子、柚子、砂糖橘 | 维C 丰富，耐运输 |

## 回复原则

- 客户问"现在吃什么水果好" → 优先推荐当季水果
- 反季水果需提示"口感可能不如当季，价格略高"
- 不确定季节时引导客户"请问您想了解哪种水果？"
