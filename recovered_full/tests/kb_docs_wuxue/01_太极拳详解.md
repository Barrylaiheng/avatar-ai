# 太极拳详解（老架一路 · 陈式）

> 文档定位：《武学知识体系实战应用 SOP》在"对方长手开路 / 连续被逼退 / 体力见底"三类场景会直接引用本文的具体招式章节。知识图谱抽取时请将本章的所有小节标题与关键词，与 SOP 的 §2.1 / §3 行 / §4 Round 1 / §5 强化建议等节点连边。

---

## 0. 核心理念

**太极拳 = 以柔克刚、后发先至**。反对用硬力硬碰硬；强调**听劲**（通过皮肤触觉感知对方力量变化）、**松沉**（松肩坠肘 + 气沉丹田让重心下沉）、**粘化**（不顶不丢，顺着对方力走）。

关键词：**松沉、听劲、粘化、掤捋挤按、采挒肘靠、气沉丹田、以柔克刚、后发先至**

SOP 交叉引用关系：
- SOP §2.1 场景 A 长拳直拳开路 → 引用本文 §2.1 起势懒扎衣 / §3.2 听劲粘化 / §4 松沉
- SOP §3 切换条件表「连续被逼退至圈边」→ 切走咏春（保留本文只作为对方打过来前的先手招式）
- SOP §4 Round 1 · 试探段 → 完整走一遍本文 §2.1 的 1~4 式
- SOP §5 强化建议「切换过早」→ 本文 §4 每式站桩 3 分钟

## 1. 基本功要求（训练前必过）

### 1.1 站桩（无极桩）
- 双脚与肩同宽，膝微屈；胯根后坐，命门后撑；
- 头顶百会穴虚领顶劲，下颌微收，舌抵上腭；
- 双手在腹前抱球，肘比肩略低；
- 时间：**初级 ≥ 5 分钟 / 次**，**提高班 ≥ 15 分钟 / 次**。

### 1.2 松沉的三层阶梯
1. 第一层：肩膀不再"架起来"，抬手时**肘下坠**不抬肘；
2. 第二层：力到手腕为止，手腕以下放松像挂着毛巾（= 不握死拳）；
3. 第三层：命门后撑 + 气沉丹田，一跺脚整个人像"按在地上"一样不被推动。

### 1.3 呼吸
- 所有动作配合 自然腹式呼吸：**招式启动时吸气，招式落点定型时呼气**；
- 禁止憋气；禁止耸肩呼吸。

## 2. 老架一路（前 13 式 · 实战最常用部分）

### 2.1 起势 · 懒扎衣 · 六封四闭 · 单鞭（前四式，SOP Round1 必走）

> 对应 SOP：§4 Round 1「太极拳 · 试探」的完整招式串。关键词：**起势、懒扎衣、六封四闭、单鞭**

1. **起势**：双脚开步与肩同宽 → 双手前掤（掤手）→ 下按 → 回到腹前。
   - 要点：起势的一掤一按就是 听劲 的开始；不要一上来就发力。
   - 关联关键词：掤手、听劲、松沉

2. **懒扎衣**：身体微右转 → 右手划弧至右膝外 → 再向右上方拉开成弓步。
   - 要点：拉开的瞬间，对方长拳打过来的直拳就会被我的"右掤"化到侧面（= SOP §2.1 化解直拳的**关键一式**）。
   - 关联关键词：掤、化劲、长拳直拳、粘化

3. **六封四闭**：由懒扎衣弓步收回，双手合在胸前右下方，像"封闭四面八方"。
   - 要点：此式是**捋**与**按**的组合，对方如果连续打出第二拳直拳，就用六封四闭把对方的手"封死"然后向下按出。
   - 关联关键词：捋、按、六封四闭、连续接招

4. **单鞭**：六封四闭之后向左开左步，右手向右作勾手，左手作掌推出。
   - 要点：这是**四正手最后的"挤"**，推出去的一下要用腰劲，而不是臂力。
   - 关联关键词：挤、腰劲、单鞭

### 2.2 第 5–9 式：金刚捣碓、白鹤亮翅、搂膝拗步、斜行、初收
- 只做理解用，**进入 SOP 轮转的提高班不推荐开局直接用**（节奏太慢，适合平时训练）。

### 2.3 第 10–13 式：前蹚拗步、第二斜行、再收、前蹚拗步（二）
- 作为"六封四闭封不住对方 → 继续向前推进"的备用扩展。

## 3. 推手 / 对练技法

### 3.1 定步单推手（训练用）
- 甲乙双方右手互搭，顺时针 / 逆时针轮转；
- 训练目标：让对方的任何推力**都滑到空处**，自己不顶、不丢；
- 对 SOP 的意义：场景 A 对方长手直拳过来，就是"对方先推了一下"——用定步推手练出的肌肉记忆自动化成侧面。

### 3.2 听劲 · 粘化四法（掤、捋、挤、按）— SOP §2.1 直接引用
> **本文核心章节。SOP 场景 A 的决策依据就写着这一条。** 关键词：**掤、捋、挤、按、听劲、粘化**

1. **掤（上向外）**：对方直拳打来，我的前臂像"盾牌斜 45°"一抬，把对方的直拳力引向我上方斜侧。
   - SOP 对应：《武学 SOP》§2.1 决策依据「懒扎衣拉开的瞬间化直拳」。
2. **捋（横向拉）**：对方继续前进，我顺着方向把他的手往我身侧一拉——对方自己就会失势。
3. **挤（合向前）**：对方失势想撤回，我就合两手向前"挤"出去。
4. **按（下向前）**：对方用硬力顶回来，我改挤为按，把劲按到对方丹田下方。

口诀：**「掤上捋侧挤前按下」**，四种劲轮转一圈就是一个完整的化解+反击闭环。

### 3.3 采挒肘靠（四隅手，少用但必懂）
- 采 = 抓拿；挒 = 横拨；肘 = 肘击；靠 = 肩靠；
- 进入 SOP 提高班三段轮转时，只在 Round1 的**最后 5 秒**尝试用"靠"把对方顶退一步。

## 4. 松沉心法（SOP §5「切换过早」的修复训练）

> 对应 SOP §5 复盘模板的强化建议"切换过早"。

训练处方：
- 回到本文 §1.1 无极桩，每步站桩 3 分钟 × 5 组；
- 然后把**懒扎衣、六封四闭、单鞭**三式，每式放慢到 20 秒做完一遍，连续 10 遍不憋气；
- 结束时再站桩 5 分钟收功。

关键词强化共现（为图谱连边用）：**松沉、无极桩、懒扎衣、六封四闭、单鞭、切换过早、复盘、强化建议**

## 5. 常见错误与修正

| 错误现象 | 根源 | 修正方法 |
|---|---|---|
| 打懒扎衣时肩膀高耸 | 没有松沉，"用手臂力量在抬" | 回到无极桩 + §4 放慢练习 |
| 捋的一瞬被对方带倒 | 捋只动手不动腰 | 捋时腰先转 45° 再带手 |
| 按出去对方丝毫不动 | 按的力在肩，不在丹田 | 六封四闭 呼气时 命门后撑，气沉丹田再按 |
| 与对方硬顶 | 没理解"以柔克刚" | 回 §0 核心理念读 3 遍 + 定步推手 30 分钟 |

## 6. 与其他拳法的关系图谱（显式声明，便于 Graph 抽出跨文档边）

- **对 咏春拳 的关系**：
  - 太极拳是**远距粘化**（1.5 米左右），咏春拳是**近距快打**（0.8 米以内）；
  - SOP §3 切换条件：被逼退到圈边（空间 < 1 米）太极拳就切咏春拳；
  - 切换的衔接招式：太极拳的 **单鞭推出去后收势** → 立刻收步到中线起 **咏春问手**（详见《咏春拳详解》§2 / §4.2）。

- **对 洪拳 的关系**：
  - 太极拳是"接"，洪拳是"顶"；
  - SOP §3 切换条件：体力 < 30% 时由洪拳切回太极拳恢复呼吸；
  - 切换的衔接招式：洪拳 **沉桥** 卸力后 → 立刻太极拳 起势 抱球呼吸（本文 §2.1 第 1 式）。

- **对 SOP 总表的关系**：
  - 本文每一个关键词和章节标题，都在《武学 SOP》里至少出现 1 次；
  - 图谱要求：SOP 的"场景 A / Round 1 / 强化建议切换过早"三个节点，与本文对应章节必须**存在 1 跳或 2 跳可达路径**。
