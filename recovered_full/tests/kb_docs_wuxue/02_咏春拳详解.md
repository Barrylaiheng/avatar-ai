# 咏春拳详解（小念头 · 寻桥 · 标指）

> 文档定位：《武学知识体系实战应用 SOP》在"对方近身短打 / 被逼退至圈边 1 米以内 / 三段轮转 Round3 终结段"三类场景会直接引用本文的 小念头、黐手、日字冲拳 等章节。图谱构建时请把本节所有小节和关键词，与 SOP §2.2 / §3 表 第一二行 / §4 Round 3 / §5 强化建议 黐手 等节点连边。

---

## 0. 核心理念

**咏春拳 = 中线理论 + 短桥快打 + 黐手触觉**。
- **中线**：自己鼻尖 → 喉结 → 丹田 → 裆 的一条竖线；所有攻击**必须优先打对方中线（鼻梁、心口、丹田三点）**，所有防守**必须优先覆盖自己中线**。
- **短桥**：出拳不把手臂完全伸直，保留一段弯曲做"收回来再打第二拳"的预备；
- **黐手**：双方前臂贴在一起，不看对方眼睛，全凭**触觉**判断对方下一步出什么；
- **朝面追形**：身体永远正面朝向对方，宁可走位，也不要用侧面接招。

关键词：**中线、短桥、黐手、朝面追形、小念头、日字冲拳、问手、伏手、膀手、摊手、枕手、脱手**

SOP 交叉引用关系：
- SOP §2.2 场景 B（对方近身短打 / 贴身顶肘）→ 引用本文 §2 小念头 / §3.1 黐手 / §4.2 三连冲拳
- SOP §3 切换条件表「空间 < 1 米被逼退」→ 由太极拳切到咏春（本文 §4.2 窄空间爆发）
- SOP §3 切换条件表「连续 3 次被长手压着打」→ 由咏春切走太极拳（保留本文仅作对方被引进近身时的反击）
- SOP §4 Round 3 · 终结段 → 完整走本文 §4.2「问手→伏手→冲拳×3→膀手→再冲×2」
- SOP §5 强化建议「切换过晚」→ 本文 §3.1 黐手每日 20 分钟

## 1. 基本功要求

### 1.1 二字钳羊马（咏春马步）
- 双脚尖外八 45°，脚跟间距 = 自己一竖掌；
- 双膝向内"钳"在一起，双膝垂线不超过脚尖；
- 上身与太极一样要求 松肩坠肘、气沉丹田，但咏春**重心略前倾**（因为是近距离进攻型）。

### 1.2 中心线意识
- 站立时在脑中画自己的中线；
- 每次出拳，在脑中问自己两句话：
  1. "我这一拳打在对方中线三点（鼻梁 / 心口 / 丹田）的哪一点？"
  2. "我出拳这条线会不会被对方半路截断？如果会，我就先摊手再打。"

### 1.3 放松的拳头（与太极一致但目标不同）
- 出拳**在接触到对方皮肤的瞬间才握实**，出拳过程中手掌是放松的；
- 这个要求和太极拳松沉同源，但咏春是为了：**第二拳、第三拳可以无空隙继续上**（日字冲拳三连的基础）。

## 2. 小念头（第一套拳 · 咏春所有招式的母拳）— SOP §2.2 直接引用

> 对应 SOP §2.2 场景 B 的核心：短桥快打靠的就是小念头里磨出来的"每式都在短桥距离内完成"。
> 关键词：**小念头、日字冲拳、摊手、膀手、伏手**

小念头 = 全套路从头到尾都在原地二字钳羊马完成。重点只讲实战中最常用的 6 式：

### 2.1 起势 + 日字冲拳（咏春 = 用这一式得分）
- 步骤：二字钳羊马站好 → 双拳收回腰间（拳心向上）→ 前手打出"日字拳"：
  - 拳要立起来，拳面向前，拳面的四个骨头排成"日"字形（不是横拳，不是拳眼向下的竖拳）。
  - 打出的路线必须**严格沿着自己中线向前**，打对方心口或鼻梁。
- SOP 对应：《武学 SOP》§4 Round 3 的终结三连就是这一式连续 ×3。
- 关键词重复：**日字冲拳、中线、短桥**

### 2.2 摊手（Taan Sau）
- 前手向前下方像"摊开手掌接硬币"一样伸出去；
- 用途：对方出拳打我中线，我用摊手从**下方向上托**对方的肘，对方打空。
- SOP 衔接：太极拳 单鞭推出去后 → 我收步 → 立刻用摊手（本文）+ 日字冲拳反击。

### 2.3 膀手（Bong Sau）
- 前臂向上向外弯曲成"盾牌"，像鸟翅膀抬起；
- 用途：对方绕开我中线，从侧面打我脸，我用膀手接；
- SOP §4 Round 3 中：冲拳 ×3 后插入一个膀手"卸"对方的摆拳反击，再继续冲拳。

### 2.4 伏手（Fuk Sau）
- 手掌向下向前"伏"在对方的桥手上；
- 用途：对方想**收回拳再打第二拳**时，我伏手一压，对方手就收不回去；
- SOP §4.2 三连的第一环：**问手→伏手→冲拳**的伏手就是这一式。

### 2.5 问手（Jan Sau / Wu Sau）
- 咏春标志性"开口问一句你要不要打"的起手势；
- 前手抬到自己肩高中线前，肘下坠，掌向前；后手在自己胸口前；
- 意义：攻防一体，对方不动我就保持姿势，对方一动我先变。

### 2.6 枕手 + 拍手
- 作为小念头训练的末尾，仅用于对练衔接，非 SOP 主路径。

## 3. 黐手（咏春 = 触觉的最高训练形式）

### 3.1 单黐与双黐（SOP §5「切换过晚」修复训练 每日 20 分钟）
> 对应 SOP §5 强化建议"切换过晚"——原因就是"没在对方手刚动的那一刻就察觉"，所以要练黐手。

1. **单黐手**：
   - 甲乙双方都只用右手，互相贴在对方手腕外侧；
   - 甲做摊、膀、伏三个循环；乙做伏、摊、膀三个循环；轮转节奏 3 秒一圈；
   - 训练目标：闭着眼也能知道对方现在在摊还是在伏。
2. **双黐手**：
   - 双手同时贴。一方攻（日字冲拳打心口），一方用摊 / 膀 / 伏接；
   - 每 20 拳交换。
3. **常见错误**：
   - 用眼睛看 = 错，必须闭眼或看对方胸口；
   - 顶力 = 错，必须让对方劲落空。
4. **与太极推手的区别**：
   - 太极推手是**远距听劲**（脚稳先，化解为主）；
   - 咏春黐手是**近距触觉**（手快先，反击为主）；
   - SOP 的切换条件"空间 < 1 米"就是二者的分界线。

## 4. 实战组合（SOP Round 3 / 场景 B 直接走这一条）

### 4.1 入门级三连（新学员）
```
日字冲拳（打心口） → 摊手（接对方回拳） → 日字冲拳（打鼻梁）
```
SOP §2.2 场景 B 的新手推荐。

### 4.2 提高班六连（SOP §4 Round 3 终结段 · 必走完整）
```
① 问手（起手式）
  ↓ 对方一动
② 伏手（压住对方桥手，不让他收回去）
  ↓ 压到一半
③ 日字冲拳 × 3 （心口 → 鼻梁 → 丹田，中线三连）
  ↓ 对方必出摆拳反击
④ 膀手（抬起前臂盾牌，把摆拳卸掉到外面）
  ↓ 卸力的瞬间
⑤ 日字冲拳 × 2 （鼻梁 → 心口 补刀）
```
共 6 个动作，总时长要求 ≤ 1.2 秒（配合呼吸：吸 → 呼×5，不允许换气停顿）。

关键词：**问手、伏手、日字冲拳、膀手、中线、六连终结、Round 3**

## 5. 常见错误与修正

| 错误现象 | 根源 | 修正方法 |
|---|---|---|
| 日字冲拳打歪到对方肩膀 | 没守中线意识 | 对墙画一条竖线，每天单拳空击 200 次沿线走 |
| 冲一拳对方就躲开，第二拳跟不上 | 手臂伸太直丢了短桥 | 回到小念头 §2.1，出拳时肘永远留 30° 弯曲 |
| 黐手时忍不住看对方手 | 没形成触觉依赖 | 戴眼罩练单黐手，每天 20 分钟（SOP §5 强化建议标准处方） |
| 膀手一接就被对方压下来 | 肩没松、肘下坠不够 | 回到小念头 §2.3 膀手，先靠墙练单式 10 分钟 / 组 |

## 6. 与其他拳法的关系图谱（显式跨文档边源）

- **对 太极拳 的关系**：
  - 太极 远距粘化（1.5m），咏春 近距快打（0.8m 内）；
  - SOP §3 切换条件"被逼退至圈边空间<1m" → 太极切咏春；
  - 衔接招式：太极 单鞭 推完收势 → 咏春 **问手**（本文 §2.5）。

- **对 洪拳 的关系**：
  - 洪拳 硬桥硬马 = 对方压过来时顶住；咏春 = 对方顶住后我钻进去打；
  - SOP §3 切换条件"连续被下潜 2 次 / 险些摔倒" → 咏春切洪拳（防摔）；
  - 衔接招式：咏春 **伏手** 压完 → 洪拳 **沉桥** 顶住对方下潜的肩（详见《洪拳详解》§3.2 / §4.3）。
