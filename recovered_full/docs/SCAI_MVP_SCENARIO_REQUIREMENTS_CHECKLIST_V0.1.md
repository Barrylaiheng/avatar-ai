## 1. 联系人角色清单（决定：谁 → AI 可以回？谁 → 必须转主人本人？谁 → 直接拉黑？）

> 填法：每一个联系人或联系人群，填角色、AI 回复权限、触发条件、示例。

|---------|---------------------------|-----------------------------------------------|--------------------|-----------------|-------------------|
| **一级黑名单（AI 绝对不回）** | 老婆 / 丈夫 / 爸妈 / 儿女 / 直系老板（你的直属上级）| ✅ 一律弹提醒给主人本人处理，AI 绝不回复 / ❌ 发消息"主人正在忙请稍后" | 匹配「微信号 / 企业微信工号 / 手机号 / 备注名包含关键字」 | 例：老婆发来任何消息 → 桌面右下角弹 Toast「您老婆发来消息请亲自回复」+ 电脑响一声；AI 不写任何回复内容 | （这里你把具体的联系人列出来，或者备注名关键字） |

| **四级垃圾人（直接挡回 + 拉黑）** | 推销电话号 / 微商 / 骂过人的微信号 / 之前被你拉黑过的人 | ✅ 内容审核员直接挡回，AI 不回复 / ⚠️ 如果同一微信号重复发，自动拉黑（可选）| 匹配「黑名单微信号 / 关键字」 | 例：微信号 XX 发来「贷款需要吗？」→ 安全拦截，直接不回复 |  |
| **私聊里的「主人自己」** | 主人自己用微信号给 AI 分身发消息？（这个很重要！）| ⚠️ AI 怎么处理？AI 先写的框架：主人自己发的消息 = 等于「给分身下指令」，比如你说「把张三的所有聊天记录调出来给我看」= 不是普通聊天，是主人操作分身的控制指令 | （请你填：你会不会用微信自己给自己发消息来控制分身？还是说主人操作分身只通过 GUI 的 Sidebar 5 页？如果会 — 需要哪些控制指令？） | 例：主人自己的微信号发来「/whois 张三」 → 分身调出张三的档案展示；主人说「/regen 李四 刚才那条回复重新写」→ 重新生成 |  |
