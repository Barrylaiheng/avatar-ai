## 这是什么

Avatar AI 是一款 Windows 桌面端 AI 智能体工作台。你给它定义一个**角色**（比如"专属客服"、"销售顾问"），喂它**资料**（文档、话术、产品手册），绑上你常用的**沟通渠道**（公众号、企微、飞书、钉钉、PC 微信）——它就变成了一个能替你干活的数字分身。

**它不是**：
- 一个聊天机器人 demo
- 一个开源大模型
- 需要你懂 prompt engineering 才能用的开发者工具

**它是**：给普通用户用的、开箱即用的、能真正替你省时间的 AI 桌面应用。

## 面向谁

- **个人博主 / 自媒体**：让 AI 帮你回粉丝私信、整理评论要点
- **电商微商**：上架产品资料，AI 自动接待、跟进、复购提醒
- **小企业 / 工作室**：一个员工价的 AI 客服 + 销售 + 知识库 + 日程助理
- **私域运营者**：把资料灌进去，让 AI 在朋友圈/社群/私聊 7×24 值守
- **内容创作者**：上传历史内容，AI 帮你回复读者、整理素材、生成初稿

## 核心功能

### 身份模拟
AI 学习你或团队的语气、习惯、偏好——回复不像机器人，像你本人。

### 知识增强
上传 Word / PDF / Markdown / TXT / Excel 等文档，自动切片入库。回答时检索+引用，有据可查。

### 记忆进化
从对话中自动提炼用户画像和偏好，每 24 小时整理一次，越用越懂人。

### 应用市场（v2.0 新增）
给智能体装「手」——选品导购、定时发消息、内容创作、多渠道转发等扩展能力。

### 多渠道对接
| 渠道 | 适用 tier | 说明 |
|---|---|---|
| 微信公众号 | 全版本 | 官方消息 API |
| 企业微信 | 全版本 | 客户联系 / 会话存档 |
| 飞书 | 全版本 | IM / 文档 / 日历 |
| 钉钉 | 全版本 | IM / 审批 / 通讯录 |
| **PC 微信客户端** | **特殊版** | 逆向集成，合规性要求限制 |

### 本地优先
数据保存在你自己电脑上（SQLite），不经第三方服务器。云端只负责授权校验和应用市场索引。

## 常见问题

> **杀毒软件误判怎么办？**

本工具未购买代码签名证书（OV 证书约 ¥3000+/年，MVP 阶段暂缓），Windows Defender 或其他杀毒可能把未知 EXE 标记为风险。解决方法：从隔离区还原，或关闭实时防护后再启动。软件本身不联网（除云端授权校验 + 你绑定的渠道 API），不上传任何本地数据。

> **免费版和付费版有什么区别？**

看上面的权益表。免费版 2 个智能体、不能用知识库/记忆/应用市场/PC 微信，但能正常对接公众号、企微、飞书、钉钉。

> **要不要懂 prompt engineering？**

不需要。选角色模板后，系统自动给你一套合理的人设 + 开场白 + 输出风格。你只需要改改细节或直接开用。
