### 功能

- **身份模拟**：AI 学习你的语气、习惯、偏好，回复像你本人
- **知识增强**：上传文档自动切片入库，回答时检索引用
- **记忆进化**：从对话中提炼用户画像，每 24 小时自动整理
- **消息自动回复**：对接你常用的沟通渠道，7×24 常驻值守
- **本地存储**：数据保存在你自己电脑上，不经第三方服务器
